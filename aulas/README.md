# Aulas — material não normativo

Os arquivos HTML desta pasta são materiais didáticos e registros históricos do
curso. Eles podem mostrar estruturas, comandos ou convenções usados em outros
momentos e não definem as regras atuais do EmpresTI.

Em caso de divergência:

- Use `AGENTS.md` e `rules/restriction.md` para autoridade e escopo.
- Use `docs/adr/` para decisões técnicas vigentes.
- Use `docs/specs/` para comportamento das funcionalidades.
- Use as demais rules para os procedimentos aplicáveis.
- Se ADR e spec discordarem, pare e avise; não escolha um dos dois.

Nunca execute comandos copiados das aulas sem conferi-los contra essas fontes.
